<h2>הכנה לתרגול ושימוש בטוח בסביבת המעבדה</h2>
<ul>
  <li>ודאו שיש לכם גישה לסביבת המעבדה ולפרטי ההתחברות שסופקו בסדנה. בתרגול עצמאי נדרשים מנוי <bdi dir="ltr">Azure</bdi> והרשאות מתאימות.</li>
  <li>לפני הרצת קובצי הדגמה, קראו את הפקודות והתאימו את המנוי, שמות המשאבים והאזור להוראות התרגיל. אל תריצו אותם בסביבת ייצור.</li>
  <li>יצירת משאבים במנוי אישי עלולה לגרור חיובים. בסיום התרגול מחקו רק את משאבי התרגיל שלכם, בהתאם להוראות המעבדה.</li>
  <li>אל תפרסמו סיסמאות, מפתחות גישה, טוקנים או פרטי התחברות בקוד, בסיכומים או בצילומי מסך.</li>
</ul>
